# Проверка конфликтов условий ветвления

## Назначение


Для одной страницы может быть задано несколько условий перехода на разные страницы. После заполнения страницы должно выполниться **не более одного условия**. Если два условия могут одновременно быть истинными, возникает неоднозначность при выборе следующей страницы.

Для предотвращения таких ситуаций при создании и изменении условий выполняется проверка на наличие конфликтов.

Проверка выполняется при создании и изменении условий ветвления. Если обнаруживается конфликт, операция завершается ошибкой, а пользователю возвращается сообщение о конфликтующих условиях.

---

## Основная идея

Каждое условие представляется в виде дерева логических операторов:

- `AND`
- `OR`
- `ATOM`
- `NOT_ATOM`

Для анализа условий дерево преобразуется в **дизъюнктивную нормальную форму (DNF)**.

DNF представляет условие как дизъюнкцию конъюнктивных членов:

```text
(Q1 ∧ Q2)
∨
(Q3 ∧ Q4)
∨
(Q5)
```

Каждый конъюнктивный член (Clause) представляет один возможный сценарий выполнения условия, то есть один набор ответов, при котором условие истинно.

---

## Преобразование дерева условий в DNF

Каждое условие хранится в виде дерева логических операторов.

Листья дерева содержат атомарные условия (`ATOM`, `NOT_ATOM`), а внутренние вершины содержат логические операции (`AND`, `OR`).

```text
            AND
           /   \
         OR    Q3
        /  \
      Q1   Q2
```

Преобразование выполняется рекурсивным обходом дерева снизу вверх.

### Шаг 1. Обработка листьев

Если текущий узел является атомарным условием, рекурсия завершается.

Из атома создаётся один `Clause`, содержащий один литерал. Литерал — это одно атомарное условие, например Q1 = A или NOT(Q2 = B).

Например

```text
Q1 = A
```

превращается в

```text
[
    { Q1 = A }
]
```

Отрицательный атом

```text
NOT(Q1 = A)
```

становится

```text
[
    { NOT(Q1 = A) }
]
```

---

### Шаг 2. Обработка OR

Для узла `OR` сначала рекурсивно преобразуются все дочерние поддеревья.

Каждое из них уже возвращает свою DNF.

После этого результаты просто объединяются.

Например

```text
      OR
     /  \
    Q1    Q2
```

левый сын возвращает

```text
[
    {Q1}
]
```

правый

```text
[
    {Q2}
]
```

Результат

```text
[
    {Q1},
    {Q2}
]
```

Никаких дополнительных преобразований выполнять не требуется, поскольку DNF уже представляет собой дизъюнкцию (`OR`) нескольких `Clause`.

---

### Шаг 3. Обработка AND

Для узла `AND` также сначала рекурсивно вычисляется DNF каждого дочернего поддерева.

После этого необходимо получить все возможные сочетания их `Clause`.

Для этого используется декартово произведение.

Например

левое поддерево вернуло

```text
[
    {Q1},
    {Q2}
]
```

правое

```text
[
    {Q3},
    {Q4}
]
```

Декартово произведение даст четыре комбинации

```text
{Q1} + {Q3}
{Q1} + {Q4}
{Q2} + {Q3}
{Q2} + {Q4}
```

После объединения литералов каждой пары Clause получится

```text
[
    {Q1, Q3},
    {Q1, Q4},
    {Q2, Q3},
    {Q2, Q4}
]
```

Именно это и является DNF выражения

```text
(Q1 OR Q2) AND (Q3 OR Q4)
```

Таким образом каждый вызов рекурсивной функции возвращает уже готовую DNF для своего поддерева.

Логика работы функции зависит только от типа текущего узла:

| Тип узла | Что возвращается |
|----------|------------------|
| `ATOM` | Один `Clause` с одним литералом |
| `NOT_ATOM` | Один `Clause` с отрицательным литералом |
| `OR` | Объединение DNF всех дочерних узлов |
| `AND` | Декартово произведение DNF дочерних узлов с объединением литералов |

---

## Удаление невозможных Clause

После формирования каждого Clause выполняется проверка на наличие внутренних противоречий.

Если внутри одного `Clause` одновременно присутствуют

```text
X
¬X
```

или

```text
Q = A
Q = B
```

для одного вопроса,

то такой `Clause` является невыполнимым и удаляется.

### Пример

До упрощения:

```text
(Q1 = A AND NOT(Q1 = A))
OR
(Q2 = B)
```

После удаления невозможного `Clause`:

```text
(Q2 = B)
```

---

## Проверка конфликтов условий

После преобразования каждого условия в DNF все `Clause` двух условий сравниваются попарно.

При объединении проверяется, не появились ли противоречащие друг другу литералы. Если после объединения не возникает противоречий, значит существует набор ответов, удовлетворяющий обоим условиям одновременно.

Следовательно, условия конфликтуют.

### Пример

**Условие 1**

```text
Q1 = A
AND
Q2 = B
```

**Условие 2**

```text
Q1 = A
AND
Q3 = C
```

Оба условия одновременно выполняются при ответах

```text
Q1 = A
Q2 = B
Q3 = C
```

Следовательно, условия конфликтуют.

---

## Отсутствие конфликта

Если для каждой пары `Clause` найдено хотя бы одно противоречие, то пересечения множеств истинности отсутствуют.

### Пример

**Условие 1**

```text
Q1 = A
```

**Условие 2**

```text
Q1 = B
```

Эти условия не могут выполниться одновременно, поскольку один и тот же вопрос не может иметь два различных ответа.

---

## Почему используется DNF

Исходное дерево условий может иметь произвольную вложенность операторов `AND` и `OR`.

Непосредственно сравнивать два таких дерева сложно.

После преобразования в DNF каждое условие становится набором независимых вариантов выполнения (`Clause`).

Это позволяет проверять конфликт не между двумя деревьями целиком, а между отдельными наборами литералов, что значительно упрощает алгоритм.

---

## Алгоритм

1. Получить все условия страницы.
2. Для каждого условия построить DNF.
3. Исключить невыполнимые `Clause`.
4. Для каждой пары условий:
   1. сравнить все `Clause` первого условия со всеми `Clause` второго;
   2. если найдена пара `Clause` без противоречий — условия конфликтуют.
5. Если конфликт найден — отклонить создание или изменение условия.
