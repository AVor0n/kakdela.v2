## Крит сценарии
1. "Создать опрос" (на приветственной) -> регистрация -> авторизация -> "Создать опрос" (должен создаться неопубликованный опрос в бд)
2. "Создать опрос" -> редактирование названия и описания опроса -> добавление одной страницы с несколькими вопросами разных типов -> добавление завершающей страницы -> публикация (должен быть сохранен опубликованный опрос в бд)
3. "Создать опрос" -> "Настройки" -> указание обязательных респондентов -> публикация (должны отправиться уведы на почту юзерам)
4. "Создать опрос" -> публикация -> указание обязательных респондентов -> публикация (должны отправиться уведы на почту юзерам)
5. "Создать опрос" -> публикация -> указание редактора и аналитика -> публикация (должны выдаться права)
6. переход создателя на опубликованный опрос -> "Ответы" -> "Скачать ответы (xlsx)" (выдается корректный файл с правильным названием)
7. иконка профиля -> выйти -> переброс на главную страницу без иконки профиля сверху
8. переход по ссылке на опрос -> "Перейти к опросу" -> прохождение -> показ завершающей страницы (в бд сохранено прохождение)
9. переход по ссылке на опрос -> "Перейти к опросу" -> сохранено незавершенное прохождение
10. "снять с публикации" -> опрос не доступен по ссылке
11. переход по ссылке на порос только для авторизованных -> "Перейти к опросу" -> окно авторизации

## Тест-сьюты
#### Регистрация
предусловие: пользователь не зарегистрирован
шаги: ввод корректных данных для регистрации -> нажатие кнопки "Зарегистрироваться"
ожидаемый результат: 201.created + AccountResponseDto с данными созданного юзера от бэка, фронт перенаправляет на страницу логина
#### Авторизация
предусловие: пользователь зарегистрирован
шаги: ввод корректных логина и пароля -> нажатие кнопки "Войти"
ожидаемый результат: 204.no_content от бэка, фронт перенаправляет на страницу с опросами
#### Создание опроса
предусловие: пользователь зарегистрирован, находится на странице опросов
шаги: нажатие "Создать опрос"
ожидаемый результат: 201.created + SurveyResponseDto с данными опроса от бэка, фронт перенаправляет на страницу редактора
#### Публикация
предусловие: пользователь создал опрос
шаги: нажатие кнопки "Опубликовать" (фронт отправляет put на изменение статуса опроса)
ожидаемый результат: 200.ok + SurveyResponseDto с данными опроса от бэка, фронт перенаправляет на страницу с опросами
#### Отправка уведомлений
предусловие: пользователь создал опрос, опубликовал его, указал обязательных респондентов
шаги: нажатие кнопки "Опубликовать"
ожидаемый результат: 200.ok + SurveyResponseDto с данными опроса от бэка, отработал сервис отправки уведомлений, юзерам пришли письма
#### Выдача прав
предусловие: пользователь создал опрос
шаги: ввод почты юзера-аналитика -> нажатие кнопки "Добавить"
ожидаемый результат: 201.created+ PermissionResponseDto с данными о выданной роли от бэка, фронт открывает поле ввода новой почты, сохраненный юзер с правами отображается ниже
#### Импорт ответов в эксель
предусловие: у пользователя есть опубликованный опрос
шаги: нажатие кнопки "Ответы" -> нажатие кнопки "Скачать ответы"
ожидаемый результат: 200.ok + файл с правильным названием от бэка, пользователю в браузере скачивается файл
#### Логаут
предусловие: пользователь залогинен
шаги: нажатие на иконку профиля -> нажатие кнопки "Выйти"
ожидаемый результат: 204.no_content от бэка, фронт перенаправляет на главную страницу, иконка профиля не отображается
#### Сохранение незавершенного прохождения
предусловие: пользователь перешёл по ссылке на опрос, находится в превью опроса
шаги: нажатие кнопки "Перейти к опросу"
ожидаемый результат:
1. 201.created + ResponseCreateResponseDto с данными о сохраненном незавершённом прохождении
2. 200.ok + SurveyPageResponseDto с данными первой страницы от бэка, фронт перенаправляет на страницу прохождения
#### Сохранение прохождения
предусловие: пользователь заполнил обязательные все вопросы, находится в окне прохождения
шаги: нажатие кнопки "Отправить"
ожидаемый результат: 200.ok + ResponseResponseDto с данными прохождения от бэка, фронт перенаправляет на завершающую страницу
#### Попытка доступа к неопубликованному опросу
предусловие: опрос снят с публикации, пользователь не имеет прав на его редактирование/просмотр
шаги: пользователь переходит по ссылке на опрос
ожидаемый результат: 403.forbidden "У вас нет прав доступа к опросу" от бэка
#### Попытка доступа к опросу только для авторизованных
предусловие: опрос опубликован с опцией "только для авторизованных"
шаги: неавторизованный пользователь переходит по ссылке на опрос -> нажатие кнопки "Перейти к опросу"
ожидаемый результат: 401.unauthorized от бэка, фронт перенаправляет на авторизацию
