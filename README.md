# KakDela-v2 - Сервис для создания опросов
## Что за проект?
Внутренний конструктор опросов для hh.ru, со входом по аккаунту пользователя hh.ru, гибкой логикой вопросов и нативной интеграцией с экосистемой hh.
## Основные фичи
##### ✅ - уже реализовано
##### ❌ - ещё нет, но планируем реализовать
##### 🟡 - планы для развития

- Базовая авторизация ✅
- Возможность создать опрос с заголовком, описанием и разными видами ответов (короткий текст, длинный текст, выбор одного, выбор нескольких) ✅
- Возможность пройти опрос ✅
- Просмотр результатов опроса ❌
- Предпросмотр опроса ❌
- возможность пропускать вопросы (обязательный/опциональный ответ) ✅
- Финальный экран с произвольным текстом и картинкой ❌
- Автосохранение черновика опроса ❌
- Логика переходов между вопросами ❌
- ReachText (markdown) ❌
- Экспорт ответов в Excel (.xlsx)  ❌
- Импорт вопросов из Excel (.xlsx)  ❌
- Шаблоны опросов ❌
- Напоминания о незавершённом опросе ❌
- Совместное редактирование опроса ❌
- Импорт опросов из других сервисов (Google формы, Kakdela)
- Дедлайн прохождения опроса 🟡
- Ответы в случайном порядке 🟡
- Api для интеграции 🟡
- Dnd блоков/ответов 🟡

## Инструкции по запуску
Приложение поднимается одной командой из под docker
#### dev версия (подробные логи, дополнительный контейнер с pgAdmin4, sprind_ddl_auto=update):
```
docker compose -f docker-compose.yml up --build
```
#### prod версия (только error логи, образы подтягиваются с dockerhub, sprind_ddl_auto=validate):
```
docker compose -f docker-compose.prod.yml up --build
```
